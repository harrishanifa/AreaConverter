Kalkulator Keluasan (PWA)

Cara guna di komputer: buka index.html terus dalam pelayar (berfungsi tanpa pemasangan).

Untuk pasang sebagai aplikasi (telefon/PC) dan guna luar talian:
1. Muat naik SEMUA fail dalam folder ini ke hos HTTPS, cth. GitHub Pages atau Netlify Drop (app.netlify.com/drop - seret folder ini sahaja).
2. Buka pautan itu di Chrome (Android/PC) atau Safari (iPhone).
3. Android/PC: tekan butang "Pasang aplikasi" atau menu > Install app.
   iPhone: Kongsi > Add to Home Screen.
